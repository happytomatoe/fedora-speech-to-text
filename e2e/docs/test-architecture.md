# E2E Test Architecture

## Overview

This document describes the current E2E test architecture for the voice-to-text GNOME extension.

## High-Level Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
```

## Key Components

### 1. QEMU VM
- **Memory**: 4GB
- **CPU**: 2 cores
- **Disk**: QCOW2 base image
- **Network**: User-mode networking (10.0.2.2 → host)

### 2. GNOME Extension
- **UUID**: `voice-to-text@happytomatoe.com`
- **Features**: Hotkey recording, preferences, output methods
- **D-Bus**: `com.happytomatoe.VoiceToText`

### 3. Voice Service
- **Provider**: Parakeet (HTTP mode)
- **Endpoint**: `http://10.0.2.2:5092` (host Parakeet)
- **Audio**: Captures from virtual microphone
- **Output**: Types via dotool

### 4. Parakeet Container
- **Image**: `ghcr.io/achetronic/parakeet:latest`
- **Port**: 5092 (host) → 5092 (container)
- **Model**: `nvidia/parakeet-tdt-0.6b-v3`
